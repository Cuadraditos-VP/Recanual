# Liquidacion Caja de Empleados

App empaquetada como PWA para GitHub Pages.

## Subir

1. Crea un repositorio publico.
2. Subi a la raiz: index.html, manifest.webmanifest, sw.js, la carpeta icons/ y este README.
3. Settings, Pages, Deploy from a branch, branch main, carpeta / (root), Save.
4. Abri la URL de Pages, por ejemplo https://usuario.github.io/nombre-del-repo/

## Instalar

- Android, Chrome: menu, Agregar a la pantalla principal o Instalar app.
- iPhone, Safari: Compartir, Agregar a pantalla de inicio.
- Escritorio, Chrome o Edge: icono de instalar en la barra de direcciones.

Los datos quedan en el navegador de ese dispositivo. La primera vez hace falta internet para Chart.js. Si actualizas la app, cambia caja-v1 por caja-v2 en sw.js.
